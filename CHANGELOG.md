# Changelog

All work on the Flame in Freefall prototype, in the order it landed. Entries are written as a short
human note rather than a conventional commit log, so a reader can follow the build.

## Prototype build

- Setting up the project shell — header, navigation, footer and the dark navy token set
- Adding the demonstration catalog with recorded and deliberately missing conditions
- Building the filter and faceting engine behind the experiment explorer
- Writing the match and abstention rules that decide whether two tests can be compared
- Adding the shared component layer — cards, badges, state blocks, media placeholders
- Building the experiment explorer with search, filters and the coverage matrix
- Adding the comparison workspace with factor selection, suggested pairs and the match check
- Building the evidence and results view with traceability and limitations
- Adding the experiment detail page with the full catalog row and provenance
- Adding the data notes screen with the honesty table and backend connection points
- Wiring the router, page registry and delegated actions in the app bootstrap
- Adding honestly labelled empty, loading and no-suitable-comparison states
- Polishing spacing, focus states and the tone of the plain-English gap statements
- Making the layout responsive for tablet and mobile and adding the print stylesheet
- Writing the design notes for screen structure and visual direction
- Documenting the backend endpoints the frontend expects
